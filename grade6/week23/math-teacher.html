Unit 5: Expressions and Equations · Week 23 · Math · Teacher Plan

Solving One-Step Equations

Lesson length: 60 minutes live, plus the after-class interactive lesson

Objectives

  • Explain the difference between an expression and an equation, and what a solution is.
  • Solve one-step equations using inverse operations, including equations with rational numbers.
  • Check a solution by substitution.
  • Write a one-step equation to represent a real-world situation and solve it.
  • Find a missing price, quantity or rate using equations.

Standards

  • MA.6.AR.2.1: Given an equation or inequality and a specified set of integer values, determine which values make the equation or inequality true or false.
  • MA.6.AR.2.2: Write and solve one-step equations in one variable within a mathematical or real-world context using addition and subtraction, where all terms and solutions are integers.
  • MA.6.AR.2.3: Write and solve one-step equations in one variable within a mathematical or real-world context using multiplication and division, where all terms and solutions are integers.
  • MA.6.AR.2.4: Determine the unknown decimal or fraction in an equation involving any of the four operations, relating three numbers, with the unknown in any position.
  • MA.6.AR.1.1: Given a mathematical or real-world context, translate written descriptions into algebraic expressions and translate algebraic expressions into written descriptions.
  • Financial literacy: unit prices, discounts and checking receipts (Jump$tart Spending and Saving).

Materials

  • The interactive lesson
  • A clothes hanger, 2 cups and string, about 30 pennies or beans, an envelope
  • Paper, pencil, optional real receipts
  • Printable practice page

Vocabulary

  • equation: A mathematical sentence that says two expressions are equal, using an equal sign.
  • solution: A value of the variable that makes an equation true.
  • inverse operations: Operations that undo each other: addition and subtraction, multiplication and division.
  • isolate: To get the variable alone on one side of an equation.
  • properties of equality: Rules saying that doing the same operation to both sides keeps an equation true.
  • unit price (review): The price for one item or one unit of measure, from Units 1 and 3.

Key questions to ask

  • What operation is being done to the variable?
  • What undoes it?
  • Did you do the same thing to both sides?
  • Does your answer make the original equation true?

Common mistakes to watch for

  • Using the same operation instead of the inverse.
  • Doing an operation to only one side.
  • An expression can be solved.
  • Forgetting to answer the question with units.

Support (if the student is struggling)

  • Use the hanger balance or a drawn balance for every problem.
  • Provide an inverse-operations chart.
  • Allow guess-and-check before formal solving.

Challenge (if the student is ready for more)

  • Solve (5/6)x = 2.5 and explain each step.
  • Solve Maya's two-step equation 9n + 4 = 85 and explain each step.

Background for the teacher

Two-step equations are not required by Grade 6 B.E.S.T. (MA.6.AR.2.2 and 2.3 are one-step; 2.4 covers decimal and fraction unknowns); the reconnect and challenge preview them informally. Inequalities follow in Week 24. Prices are practice figures.

How the lesson runs

During the live lesson, the student shares their screen and answers the Reconnect questions and the Learn checks live while you teach. The Hands-On activity, Think Deeper and Exit Check are completed after class.

Scoring

The interactive lesson scores itself: full points on the first try, half points on the second try, then the answer and explanation appear. Mastery is 85. Written responses arrive in your results email with the score; score them with the rubric below before the student moves on.

Answer key: interactive lesson

Reconnect

  1. Evaluate 9n + 4 when n = 6.
    Answer: 58
    9(6) + 4 = 54 + 4 = 58.
  2. Write an expression for "a number decreased by 15."
    Answer: n − 15
    Start with the number, then subtract 15.
  3. Simplify: 5(x + 2) − 3x
    Answer: 2x + 10
    5x + 10 − 3x = 2x + 10.
  4. Maya's order formula is 9n + 4. A customer paid $40. Without solving formally, how could you figure out how many loaves they bought?
    Answer: Written response: score with the rubric.
    Rubric: A sensible backward strategy or guess and check; A correct number of loaves
    Model answer: Take away the $4 delivery fee to get $36, then divide by $9 a loaf: 4 loaves.

Learn 1: Expressions, Equations and Solutions

  1. 3x + 1 is an expression. Turn it into an equation whose solution is x = 4.
    Answer: 3x + 1 = 13
    3(4) + 1 = 13, so set the expression equal to 13.
  2. Test n = 5, 6, 7 and 8 in 6n = 42. Which value is the solution?
    Answer: 7
    6(7) = 42; 6(8) = 48.
  3. Explain the difference between an expression and an equation in your own words, with an example of each from shopping.
    Answer: Written response: score with the rubric.
    Rubric: Explains the difference in your own words; A shopping example of each
    Model answer: An expression is like a price formula, such as 4p + 3 for 4 shirts plus $3 shipping. An equation says two things are equal, such as 4p + 3 = 39, which tells me the total was $39.

Learn 2: Solving with Inverse Operations

  1. Solve: x − 17 = 29
    Answer: 46
    Add 17 to both sides: x = 46.
  2. Solve: 8p = 96
    Answer: 12
    Divide both sides by 8: p = 12.
  3. Solve: t/6 = 4.5
    Answer: 27
    Multiply both sides by 6: t = 27.
  4. Solve: (3/4)n = 18
    Answer: 24
    Multiply both sides by 4/3: n = 24. Check: 3/4 of 24 is 18.
  5. To solve x + 12 = 30, Ana added 12 to both sides and got x = 42. Explain her mistake, give the correct solution, and show a check.
    Answer: Written response: score with the rubric.
    Rubric: Explains that she should use the inverse operation; Correct solution with a check
    Model answer: Ana should have used the inverse operation. Since 12 is added to x, she should subtract 12 from both sides: x = 18. Check: 18 + 12 = 30, which is true.

Learn 3: Writing Equations from Situations

  1. Five friends split a $65 kayak rental equally. Let s = each person's share. Write the equation.
    Answer: 5s = 65
    Five shares make $65. (Each share is $13.)
  2. A spider plant grew 4.5 inches this month and is now 18.25 inches tall. How tall was it at the start of the month? Write and solve an equation.
    Answer: 13.75 inches
    Subtract 4.5: h = 13.75 inches.
  3. Write your own one-step word problem about something in your home or homeschool, write its equation with a defined variable, solve it and check it.
    Answer: Written response: score with the rubric.
    Rubric: A realistic word problem; A defined variable and correct one-step equation; Correct solution and check
    Model answer: Problem: We need 48 cupcakes for a co-op party, and each pan holds 12. How many pans do we need? Let p = number of pans. 12p = 48. Divide both sides by 12: p = 4. Check: 12 × 4 = 48.

Learn 4: Money: Solving for a Missing Price

  1. Six identical pens cost $7.50. Write and solve an equation to find the price of one pen.
    Answer: 1.25 dollars
    6p = 7.50, so p = $1.25.
  2. A pair of shoes is on sale for $38, which is $22 off the original price. What was the original price?
    Answer: 60 dollars
    p − 22 = 38, so p = $60.
  3. A store sign says a 4-pack of juice boxes is $3.80 and a single box is $1.05. Use equations to find the unit price of the 4-pack, and decide which is the better buy.
    Answer: Written response: score with the rubric.
    Rubric: A correct equation and unit price for the 4-pack; A correct comparison and better buy
    Model answer: Let u = the price of one box in the 4-pack. 4u = 3.80, so u = $0.95. The single box is $1.05, so the 4-pack is the better buy by 10 cents a box.

Hands-On

  1. Write three balance equations you solved, how you removed objects to solve each, and whether your answer matched what was in the envelope.
    Answer: Written response: score with the rubric.
    Rubric: Three equations with correct solutions; Describes removing the same amount from both sides; Checks against the envelope
    Model answer: 1. x + 4 = 11: removed 4 pennies from each side, x = 7, and the envelope had 7. 2. x + 9 = 15: removed 9 from each side, x = 6, correct. 3. x + 2 = 10: x = 8, correct. Removing the same number from both sides kept the scale balanced every time.
  2. Describe two mystery receipts: the known prices, the total, your equation and the hidden price. Show your check.
    Answer: Written response: score with the rubric.
    Rubric: Two receipts with equations; Correct hidden prices; Checks shown
    Model answer: Receipt 1: milk $3.49, bread $2.99, hidden cereal, total $10.47. c + 6.48 = 10.47, so c = $3.99. Check: 3.49 + 2.99 + 3.99 = 10.47. Receipt 2: 3 identical notebooks, total $7.47. 3n = 7.47, so n = $2.49. Check: 3 × 2.49 = 7.47.

Think Deeper

  1. Maya wants to earn $135 this week selling loaves. She is deciding between charging $9 or $10 a loaf. Write and solve an equation for each price to find how many loaves she must sell. Then use what you know about running a business to recommend a price.
    Answer: Written response: score with the rubric.
    Rubric: Correct equations and solutions for both prices; Recommends a price with a business reason
    Model answer: At $9: 9n = 135, so n = 15 loaves. At $10: 10n = 135, so n = 13.5, which means 14 loaves to reach at least $135. I'd recommend $10 if her customers are happy to pay it, since she'd bake fewer loaves, saving flour and time. If raising the price loses customers, $9 might sell more.
  2. Write three different one-step equations, using three different operations, that all have the solution x = 12. Explain how you created them.
    Answer: Written response: score with the rubric.
    Rubric: Three correct equations with solution 12; Three different operations; Explains the method
    Model answer: x + 5 = 17, x − 3 = 9 and 4x = 48. I started with x = 12 and did the same operation to both sides: added 5, subtracted 3, multiplied by 4. Because I kept it balanced, 12 is the solution to all three.

Exit Check

  1. Solve: n + 23 = 51
    Answer: 28
    Subtract 23: n = 28.
  2. Solve: 7y = 84
    Answer: 12
    Divide by 7: y = 12.
  3. Four tickets cost $46. What is the price of one ticket?
    Answer: 11.5 dollars
    4t = 46, so t = $11.50.
  4. Why should you always check your solution, and how do you do it?
    Answer: Written response: score with the rubric.
    Rubric: Explains how to check a solution; Explains why checking matters
    Model answer: Substitute your answer into the original equation; if both sides are equal, it's right. Checking catches mistakes like using the wrong operation.

Answer key: printable page

  1. Solve: (a) x + 38 = 71 (b) y − 2.75 = 6.5 (c) 9m = 117 (d) k/8 = 5
    Answer: (a) 33 (b) 9.25 (c) 13 (d) 40
  2. Solve: (2/3)n = 14
    Answer: n = 14 × 3/2 = 21.
  3. Is x = 9 a solution of 7x = 56? Explain.
    Answer: No; 7 × 9 = 63, not 56 (x = 8).
  4. A jacket costs $54 after a $18 discount. Write and solve an equation for the original price.
    Answer: p − 18 = 54; p = $72.
  5. Eight packs of seeds cost $14. Write and solve an equation for the price of one pack.
    Answer: 8s = 14; s = $1.75.
  6. Write a one-step equation with the solution 15 and a word problem to match.
    Answer: Model: 4c = 60; four friends each paid the same amount for a $60 gift, so each paid $15.
