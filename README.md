# KCE Pathways Curriculum

Interactive K–5 curriculum lessons for KingCretot Experience Pathways.

Student-facing HTML lessons only — no answer keys or teacher materials live here.
Pre/Post worksheets and Teacher Lesson Plans are stored separately in Drive.

## Structure

grade[N]/week[N]/[subject].html

Each lesson is a standalone, self-contained HTML file — open it directly in any browser, no server required.

## Current coverage

- **Grade 3, Week 1:** Math, Reading, Science, Social Studies

## Status

Actively being built out, one grade/week at a time.
